## 🚀 三步快速啟用步驟

### 步驟 1：建立你的私人專屬 Telegram Bot（耗時約 30 秒）
1. 在手機或電腦打開 Telegram，搜尋 **`@BotFather`**（官方藍勾勾帳號）。
2. 在對話框發送：`/newbot`
3. 依照提示設定機器人名稱（例如 `BryanAgentBot`），並設定一個以 `bot` 結尾的 username（例如 `shihwei_agent_bot`）。
4. BotFather 會發給你一串 **`HTTP API Token`**（格式例如 `7123456789:AAH...`）。

## 📱 手機端如何使用？
1. 在手機 Telegram 搜尋並點開你剛剛建立的機器人。
2. 發送 `/start`，程式會自動抓取並**鎖定你的專屬 User ID（白名單機制，其他人無法存取）**。
3. 之後出門在外時：
   - 輸入 `/status`：查看電腦運行狀態。
   - 輸入 `/apk`：電腦自動將最新編譯好的 A32 / vivo 氣氛燈 APK 傳到手機。
   - 直接發送訊息（或語音）指派任務，遇到需要審查的事項，點擊手機彈出的按鈕即可！🌟
